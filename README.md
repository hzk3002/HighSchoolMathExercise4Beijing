# 高考数学真题题库（北京专用）

北京卷 **7 年高考真题 + 1 年模拟**，按 8 大专题重组，共 **412 题**。
单文件网页，**打开即用、无需安装**。

## 🌐 在线使用

**https://hzk3002.github.io/HighSchoolMathExercise4Beijing/**

手机、平板、电脑均可直接打开，无需下载。

### 离线使用

下载 `index.html`（约 11 MB），双击用浏览器打开即可，**完全离线**（公式渲染引擎与
全部插图均已内联，不依赖任何 CDN）。

## 页面功能

页面含两个标签页：

| 标签页 | 功能 |
|--------|------|
| **题库浏览** | 全文检索、按年份/题型/来源/考点筛选、目录跳转、练习模式（默认隐藏答案）、标记已做 |
| **组卷** | 勾选题目 → 拖拽排序 → 填写卷头 → 导出 PDF / Word |

### 组卷与导出

- **选题**：题卡上的「＋ 加入试卷」；或筛选后一次性「筛选结果全加入试卷」
- **排序**：试卷篮内拖拽调整；或「按题型重排」（选择题 → 填空题 → 解答题）
- **导出内容**（可多选）：试卷正文、答案页、解析页、答题卡
- **解答题留白**：0 / 6 / 10 / 16 / 24 行
- **导出格式**
  - **PDF**：点「导出 PDF（打印）」，在打印对话框里选「另存为 PDF」。A4 排版，题目自动防跨页
  - **Word**：点「导出 Word（.doc）」，生成可直接编辑的文本，公式与插图一并保留
  - **复制试卷文本**：纯文本，便于粘进微信或自行排版
- **组卷方案**：可保存为 `.json` 文件，便于在老师之间传递与复现

选题结果自动保存在浏览器本地（`localStorage`），刷新不丢失。

## 数据说明

- **来源**：8 个专题的 Word 文档（原卷 / 答案 / 解析 三版本合并）
- **专题**：集合与常用逻辑用语、复数不等式平面向量、函数与导数、三角函数与解三角形、
  立体几何与空间向量、解析几何、计数原理与概率统计、数列
- **规模**：412 题 —— 选择题 179 / 填空题 83 / 解答题 150；
  其中北京高考真题 146 题、各区模拟题 266 题；含图题目 59 题
- **公式**：原文档公式由 MathType 编写。本项目直接解析 MathType 的 MTEF 二进制结构
  转为 LaTeX（26823 处，转换率 100%），网页端由 KaTeX 渲染，图片全部内联为 base64，
  因此**完全离线可用**。

### questions.json 字段

| 字段 | 含义 |
|------|------|
| `id` | 题目唯一编号，形如 `T01-考点01 集-真题-001`（专题-考点-真题/模拟-序号） |
| `topic_no` / `topic_name` | 专题编号与名称 |
| `section` | 考点 |
| `no` | 原卷题号 |
| `year` / `region` / `exam_type` / `source_kind` | 年份 / 区县 / 考试类型 / 真题或模拟 |
| `type` | 题型（选择题 / 填空题 / 解答题） |
| `stem` / `options` | 题干 / 选项（HTML，含内联公式与图片） |
| `answer` / `analysis` / `solution` | 答案 / 分析 / 详解 |
| `raw_stem` 等 `raw_*` 字段 | 对应的**纯文本**版本（无 HTML 标签，公式为 LaTeX），便于检索与再处理 |
| `search` | 预拼接的小写检索串（题干 + 选项 + 答案 + 解析） |
| `images_missing` | 未能解析的图片占位（当前为 0） |

## 已知限制

- 有 **32 道解答题**在原始文档中即未提供参考答案，**1 题**未标注年份 —— 这是源文件的
  缺失，非解析遗漏。
- 题目内容与答案的版权归原始出处所有，本项目仅作教学与教研用途的整理。
- Word 导出的公式为排版后的矢量字形（不可在 Word 内点击编辑）；如需可编辑公式，
  需另行转换为 OMML。
- 在线版（GitHub Pages）首次打开需下载约 11 MB 页面，建议在 Wi-Fi 下加载；之后浏览器
  会缓存，再次访问很快。离线版无此问题。
